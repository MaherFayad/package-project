# Marketing site (public pages, R6)

## Purpose

The public site was rebuilt in round 6 to look, feel and animate like shopify.com (2026), using only Elba's own copy and 3D renders. The binding spec is `docs/design-refs/shopify-2026-reference.md`: section 6 is the kit API, section 7 the spacing system. Per-page build notes are `docs/audit/r6-*.md`.

## Tokens

- Marketing: `src/components/marketing/kit/tokens.css`, e.g. `--mk-bg: #02090a`, `--mk-band-green`, `--mk-band-navy`, `--mk-band-violet`, `--mk-sheet: #f5f5f3`, `--mk-section-y`, `--mk-radius-sheet`.
- App UI: `src/styles/tokens.css` (`--p-*` Polaris roles, `--e-*` Elba additions), loaded via `src/styles/globals.css`. Motion tokens and `[data-reveal]` keyframes in `src/styles/motion.css`.

Spacing system (spec section 7, desktop / tablet / phone):

| Token | Values |
|---|---|
| `--mk-section-y` | 64 / 56 / 40 (`-lg` 100 / 80 / 64, `-xl` 128 / 96 / 80) |
| Head to content | 40 / 32 / 32 (lg 80 / 64 / 48) |
| Grid gap | 24 / 24 / 16 (tight 16 / 16 / 12, bento 32 / 24 / 16) |
| `--mk-radius-sheet` | 48 / 40 / 32 |
| Container | 1260 px; gutter `max(24px, (100vw - 1260px) / 2)` / 32 / 16 |

Rules: no band padding on top of a Sheet, same-tone neighbours collapse, no negative gaps, 60ch text measure, and every page is checked by `e2e/marketing-spacing.spec.ts`.

## Page rules (spec section 6)

- The first section is `<Sheet hero>`. Never wrap the LCP headline in `Reveal`.
- No three.js on first load of marketing pages; use posters and lazy 3D. `npm run test:size` gates first-load JS at 200 KB gzip.
- Budgets: phone LCP under 2.5 s, CLS under 0.1, INP under 200 ms.
- WCAG 2.2 AA; moving content has a pause control (SC 2.2.2); `prefers-reduced-motion` gives a static page.
- No fabricated social proof, no Shopify logo, copy or images.
- Kit strings in `mk.*`; page copy in the page's own `copy.ts` or namespace. Arabic labels are noun forms (see `i18n-and-copy.md`).
- Never import `@/components/ui` (the barrel); import `@/components/ui/Button` and so on.

## How to add a section or page

1. Compose kit components inside `Sheet` / `Container`; use the `data-mk-*` attributes the kit sets (`data-mk-container`, `data-mk-band`, `data-mk-head`, `data-mk-grid`) so the spacing spec can measure them.
2. Put strings in `copy.ts` (English object fixes the shape, Arabic must match) or in `mk.*` for kit chrome.
3. Add the page to `PAGES` in `e2e/marketing-spacing.spec.ts` (and to `restyle-height.spec.ts` if it is a restyled page).
4. New renders: `scripts/marketing/render-assets.mjs` (needs ffmpeg and a seeded DB); it regenerates `kit/assets.generated.*`.
5. Run the unit copy tests and the specs below.

## Pitfalls

- **R6-AX-10 (open)**: the signed-in header overflows by 8 px at 1024. **R6-AX-18 (open)**: a focused marquee item can sit off-screen.
- **R6-AX-14, R6-AX-15**: violet band text must stay solid white; loops must stop after pause (`data-mk-motion`).
- **R4-10 / R5-PL-16 (open, decision)**: the Arabic font swap re-reports LCP and adds CLS on phones.
- **R6-RS-11 / R5-PL-19**: lookup-based 404s still render the client error shell; certain-unknown URLs are handled by the middleware.
- **R4-08 (performance)**: `inlineCss` doubles CSS in the RSC payload; the Cloudflare build turns it off (`next.config.ts`, `ELBA_TARGET`).
