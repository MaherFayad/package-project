# 3D audit: every model in the real renderer

Key: `3d` · Branch: `claude/exciting-albattani-8kzgsu-r4-3d` · Base: `781d663` (round 3 merged).
Scope: `src/components/three`, `src/lib/dieline` (core and families), `src/lib/vessels` (core and families). Engine API stays backward compatible: every existing prop, export and handle method is unchanged; additions are optional (see "API changes").

Earlier reports this one builds on: `3d-visual.md` (baseline, 370 models), `3d-engine.md`, `3d-bottles.md`, `3d-cans-flexible.md`, `3d-ecma.md`, `3d-fefco-02-05.md`, `3d-fefco-04.md`, `3d-fefco-06-09.md`, `3d-rigid-food.md`.

|---|---|---|
| Model list | `e2e/fixtures/catalogue-models.json` | All **410** models: 370 designer-ready library models (274 boxes, 96 containers) and the 40 catalogue-only family models (12 unprinted FEFCO 09 fittings, 6 moulded pulp, 4 cups / sleeve, 2 lids, 15 bags / envelopes / mailers / tags / octabin / pallet lid, 1 blister). |

### API changes (all additive)

- `CrossSection` gains `{ kind: "polygon"; sides; cornerRatio }`. Code that narrowed `kind === "round" ? … : section.depthRatio` must check `kind === "roundedRect"` instead (done in `families/cosmetic-cans/geometry.ts`).
- `SurfacePlacement` band: optional `section`. `bandSpec(…, opts.section)`.
- `polygonParts()` exported from `@/lib/vessels`.
- `DielineModel.accessories?: DielineAccessory[]`; `FamilyDraft.accessories` (rigid-tubes).
- `faceLabelGeometry(spec, faceZ, profile?)`, `petaloidRibs(profile)`, `RevolveOptions.ribs.depth` may be a function.
- `heroView` turns to the printed wall when front and right are not print faces.
