# Admin console audit (key: admin)

Scope: `src/app/[locale]/admin` (except `admin/privacy`), `src/components/admin`, admin i18n keys.
Method: Playwright as admin `+201000000001`, every admin route in `ar` and `en`, 1440×900 and 390×844, axe-core (WCAG 2.0/2.1/2.2 A+AA tags), console errors, horizontal-overflow check, keyboard checks on tabs/forms. Screenshots: `docs/screenshots/audit/admin/before-*.png` and `after-*.png`.

Severity: critical = broken flow / data / security; high = clearly wrong, ugly or inaccessible; medium = noticeable polish; low = nitpick.
