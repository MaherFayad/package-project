# Accessibility audit (WCAG 2.2 AA) — key `a11y`

Scope this round: the whole app in `ar` and `en`. **Owned and fixed here:** the shared UI kit
`src/components/ui/*` and `src/styles/tokens.css`. **Everything else is listed, not edited**, with
the owning area and an exact fix (section "Findings in other areas").

There is no round 1 file for this key, so every row below is new (ids `R2-`). Round 1 rows of
other areas that touch the kit were re-verified (section "Round 1 re-verification").

## Method

| Check | How | Coverage |
|---|---|---|
| axe-core 4.x (`@axe-core/playwright`, `docs/audit/tools/a11y-sweep.cjs`), tags `wcag2a/aa`, `wcag21a/aa`, `wcag22aa`, `best-practice` | Crawler per role (anonymous, buyer, applicant, vendor staff, admin) × locale, plus explicit lists for detail pages (`/orders/:id`, `/checkout/:designId`, `/checkout/pay/:id`, `/s/:id`, `/admin/orders/:num`, `/admin/disputes/:id`, `/admin/users/:id`, `/admin/vendors/applications/:id`, `/vendor/jobs/:num`, `/vendor/rate-cards/:id`, 404) | 254 page loads, every route in `src/app/[locale]/**/page.tsx` except `/dev/3d` and `/dev/finishes` (dev only) |
| Reflow 1.4.10 | Each page re-laid at 320 × 640; `scrollWidth > clientWidth` and off-canvas elements outside a scroll container | same 254 loads |
| Text spacing 1.4.12 | Bookmarklet values injected (`line-height 1.5`, `letter-spacing .12em`, `word-spacing .16em`, paragraph `2em`); text nodes clipped by `overflow:hidden` / `text-overflow` | same |
| `lang` / `dir` / `<title>` | Read from every page | same |
| Keyboard-only | Scripted Tab / Shift+Tab / Enter / Space / Escape / arrows; per stop: role, name, visible indicator, obscured (`elementFromPoint` at centre, 2.4.11), size (2.5.8) | Designer (3D, Face, Dieline, every panel), OTP login, checkout → proof approval → payment (decline + retry), admin refund modal, phone navigation drawer, kit showcase |
| Accessibility tree | Playwright `ariaSnapshot()` of `main` on login (each OTP step and error), payment, proof approval | ar + en |
| Contrast 1.4.3 / 1.4.11 | Every text / icon / border token pair computed from `tokens.css` (`docs/audit/tools/a11y-contrast.cjs`), plus axe `color-contrast` on every page | light theme |
| Reduced motion 2.3.3 | `reducedMotion: 'reduce'`: token values, `document.getAnimations()` still running after scroll, canvas frames sampled 1.5 s apart | `/`, `/design`, `/design/mailer-box`, `/boxes`, `/vendors`, `/catalog`, `/login`, `/dev/ui` |

Result after the fixes (final sweep on a fresh production build, 80 explicit + crawled loads,
plus the earlier 254): **0 axe violations** on every product route in both locales (the only
remaining axe hits are the out-of-scope rows below and the `/dev/ui` showcase, which renders
several Pages on one screen by design). No reflow failure at 320 px except X-02. Every page has the
right `lang`/`dir` except the global 404 (X-03).

### Verified as passing (kit)

- Modal: focus moves into the dialog, Tab / Shift+Tab cycle inside, page siblings `inert`, Escape closes and focus returns to the opener (admin refund modal, ar + en).
- Phone navigation drawer: `role=dialog aria-modal`, focus trapped (25 Tabs stay inside), Escape returns focus to "Open navigation".
- Popover: Escape returns focus to the activator, outside click and focus-out close it.
- Focus indicator visible on every kit control (screenshot `focus-indicators-en.png`): 2px #005bd3 with 1px offset on light surfaces (6.1:1), white on the top bar.
- Target size 2.5.8: axe `target-size` clean on all pages; kit checkboxes/radios have a 24 × 24 hit area, icon buttons 28–44 px.
- Text and icon tokens: every text pair ≥ 4.5:1 (lowest: secondary text on tertiary fill 4.83:1), every icon / input border ≥ 3:1 (lowest: warning icon on warning surface 3.06:1). Disabled text (2.05:1) is exempt (1.4.3).

  designer, journey, smoke, storefront, vendor; desktop + mobile): 41 passed, 4 skipped (desktop-only
  mutating flows), 1 failed: `admin.spec.ts:50` could not open ELB-26301 while `vendor.spec.ts`
  was moving the same order through QC in the other worker. Re-run alone it passes (2 passed,
  1 skipped). Pre-existing cross-spec data race, not a kit change; suggested fix for the e2e owner:
  give the two specs separate seeded orders or mark them `test.describe.configure({ mode: "serial" })`
