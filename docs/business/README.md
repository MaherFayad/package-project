# Business Kit (Phase 0 validation)

Paste-ready documents for Phase 0 of `docs/research-report.md` section 10. English with Arabic versions where the audience is Egyptian. Figures marked [ASSUMPTION] or [VERIFY] must be replaced or confirmed before use.

| File | Use it for |
|---|---|
| `customer-interview-guide.md` | 15 to 20 buyer interviews (D2C, F&B, cosmetics, agencies): screening, consent script, 20 questions EN/AR, note template |
| `vendor-interview-guide.md` | 10 print-vendor interviews: screening, 23 questions EN/AR, note template |
| `vendor-visit-checklist.md` | On-site audit: legal, machines, minimums, dies, QC, food-contact evidence, terms, portfolio photos, test job |
| `reference-jobs-rfq.md` | The 5 reference jobs with full specs, Arabic WhatsApp RFQ, quote capture sheet, margin test |
| `rate-card-template.csv` | Vendor buy-price rate card, one row per vendor + structure + material, matching `RateCard` / `src/lib/pricing` |
| `rate-card-how-to.md` | How to fill and normalise the rate card |
| `vendor-framework-agreement-outline.md` | Commercial terms for the vendor agreement (a lawyer must finalise) |
| `compliance-checklist.md` | PDPL, consumer protection, VAT, ETA, GAFI, CBE, food contact: owner, status, evidence, sources |
| `launch-metrics.md` | Free-tool funnel and order KPIs with definitions and target ranges (assumptions) |
| `go-to-market.md` | Designer referral programme, Arabic SEO plan, Instagram/TikTok loop, Ramadan/Eid calendar |

Not legal or tax advice. Personal data from interviews is handled under the consent scripts in the guides.
